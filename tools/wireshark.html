Wireshark

أداة تحليل حزم الشبكة

يعني إيه Wireshark؟

Wireshark هي أداة مفتوحة المصدر لتحليل حزم الشبكة (Packet Analyzer). بتعرضلك كل البيانات اللي بتعدي على الشبكة في الوقت الفعلي. بتستخدمها في تحليل المشاكل، اكتشاف الهجمات، وتحليل البروتوكولات.

الأداة دي بتعتبر من أهم أدوات تحليل الشبكات في العالم — وبتستخدمها الشركات الكبيرة لمراقبة شبكاتها. وبتقدر تفكك كل بروتوكول على حدة وتعرضلك تفاصيله.

الاستخدامات

  • تحليل حركة الشبكة
  • اكتشاف الهجمات
  • تحليل البروتوكولات
  • حل مشاكل الشبكة
  • اعتراض بيانات (على شبكتك)

التثبيت

# على Termux (بديل خفيف) pkg install tcpdump -y # Wireshark مش بيشتغل على Termux # للاستخدام الكامل، استخدم كمبيوتر

الأوامر الأساسية (tcpdump)

1. اعرض كل الحزم

tcpdump

2. اعرض حزم واجهة معينة

tcpdump -i wlan0

3. احفظ في ملف

tcpdump -i wlan0 -w capture.pcap

4. فلتر حسب IP

tcpdump -i wlan0 host 192.168.1.1

5. فلتر حسب البورت

tcpdump -i wlan0 port 80

الفلاتر في Wireshark

  • ip.addr == 192.168.1.1 — حسب IP
  • tcp.port == 80 — حسب البورت
  • http — حزم HTTP
  • dns — حزم DNS
  • tcp — حزم TCP
  • udp — حزم UDP
تحذير: استخدم Wireshark على شبكتك بس.

تمارين

  1. شغّل tcpdump على واجهة wlan0
  2. افتح موقع وشوف الحزم
  3. فلتر حسب IP الراوتر
