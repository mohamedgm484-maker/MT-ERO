Shodan

محرك البحث للأجهزة المتصلة بالإنترنت

يعني إيه Shodan؟

Shodan هو محرك بحث متخصص في الأجهزة المتصلة بالإنترنت (IoT, Servers, Webcams, Routers). بيعرضلك الأجهزة المكشوفة مع معلوماتها.

الأداة دي بتستخدمها في OSINT واكتشاف الأجهزة المكشوفة — وبتساعدك تحمي أجهزتك.

الاستخدامات

  • اكتشاف أجهزة مكشوفة
  • تحليل الثغرات
  • مراقبة شبكتك
  • Bug Bounty Recon

الاستخدام

1. البحث في الموقع

https://shodan.io # أمثلة للبحث apache country:EG port:22 country:EG webcam country:EG

2. استخدام API

pip install shodan shodan init YOUR_API_KEY shodan search "apache country:EG"
ملحوظة: Shodan بيعرض بيانات عامة بس.

تمارين

  1. سجّل في Shodan
  2. ابحث عن أجهزة في مصر
  3. اتعلم OSINT
