WPScan

أداة فحص مواقع WordPress

يعني إيه WPScan؟

WPScan هي أداة متخصصة في فحص مواقع WordPress. بتكشف الثغرات في القوالب، الإضافات، والإصدارات. بتستخدمها في Bug Bounty واختبار الاختراق.

الأداة دي بتعتبر الأساسية لأي مختبر اختراق بيشتغل على مواقع WordPress — وبتغطي أكتر من 50,000 ثغرة معروفة.

الاستخدامات

  • كشف إصدار WordPress
  • كشف القوالب والإضافات
  • كشف المستخدمين
  • فحص الثغرات المعروفة
  • كسر الباسوردات الضعيفة

التثبيت

# على Kali Linux sudo apt install wpscan # على Termux (صعب) gem install wpscan

الأوامر الأساسية

1. فحص أساسي

wpscan --url https://example.com

2. كشف الإضافات الخطيرة

wpscan --url https://example.com --enumerate vp

3. كشف المستخدمين

wpscan --url https://example.com --enumerate u

4. كسر الباسوردات

wpscan --url https://example.com --passwords rockyou.txt --usernames admin
تحذير: استخدم WPScan على مواقعك بس. فحص مواقع تانية جريمة.

تمارين

  1. سجّل في TryHackMe وادخل WPScan room
  2. جرب WPScan على موقع تجريبي
  3. افهم أنواع الثغرات
