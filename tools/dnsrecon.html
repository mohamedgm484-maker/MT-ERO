DNSRecon

أداة جمع معلومات DNS

يعني إيه DNSRecon؟

DNSRecon هي أداة Python لجمع معلومات DNS. بتستخدمها لاكتشاف Subdomains، Mail Servers، Name Servers، وإعدادات DNS التانية.

الأداة دي بتعتبر أساسية في مرحلة Recon — وبتوفر معلومات مهمة عن البنية التحتية للهدف.

التثبيت

pip install dnsrecon dnsrecon -h

الأوامر الأساسية

1. فحص DNS أساسي

dnsrecon -d example.com

2. فحص Zone Transfer

dnsrecon -d example.com -t axfr

3. Brute Force Subdomains

dnsrecon -d example.com -D subdomains.txt -t brt

4. فحص Reverse Lookup

dnsrecon -r 192.168.1.0/24
تحذير: استخدم DNSRecon على نطاقاتك إنت.

تمارين

  1. افحص نطاقك
  2. اكتشف Subdomains
  3. اتعلم DNS Enumeration
