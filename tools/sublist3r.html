Sublist3r

أداة اكتشاف النطاقات الفرعية

يعني إيه Sublist3r؟

Sublist3r هي أداة Python لاكتشاف النطاقات الفرعية (Subdomains) باستخدام محركات البحث ومصادر OSINT متعددة. بتستخدمها في مرحلة Recon لاكتشاف نطاقات مخفية.

الأداة دي بتعتبر الأسرع في مجالها — وبتدعم مصادر كتير زي Google, Bing, Yahoo, Baidu, Ask.

الاستخدامات

  • اكتشاف Subdomains
  • توسيع نطاق الفحص
  • اكتشاف خدمات مخفية
  • Bug Bounty Recon

التثبيت

pip install sublist3r sublist3r -h

الأوامر الأساسية

1. اكتشاف Subdomains

sublist3r -d example.com

2. استخدام مصادر محددة

sublist3r -d example.com -b google,bing

3. حفظ النتايج

sublist3r -d example.com -o results.txt

4. تفعيل Brute Force

sublist3r -d example.com -b brute
تحذير: استخدم Sublist3r على نطاقاتك إنت.

تمارين

  1. اكتشف Subdomains موقعك
  2. جرب مصادر مختلفة
  3. حلل النتايج
