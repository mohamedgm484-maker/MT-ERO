Tcpdump

أداة التقاط وتحليل حزم الشبكة

يعني إيه Tcpdump؟

Tcpdump هي أداة سطر أوامر لالتقاط وتحليل حزم الشبكة. بتستخدمها لمراقبة الشبكة، تشخيص المشاكل، وتحليل البروتوكولات.

الأداة دي بتعتبر البديل الخفيف لـ Wireshark — وبتشتغل على كل أنظمة Unix/Linux.

التثبيت

pkg install tcpdump -y tcpdump --version

الأوامر الأساسية

1. اعرض كل الحزم

tcpdump

2. اعرض واجهة معينة

tcpdump -i wlan0

3. احفظ في ملف

tcpdump -i wlan0 -w capture.pcap

4. فلتر حسب IP

tcpdump -i wlan0 host 192.168.1.1

5. فلتر حسب البورت

tcpdump -i wlan0 port 80
تحذير: استخدم Tcpdump على شبكتك بس.

تمارين

  1. شغّل tcpdump على واجهة wlan0
  2. افتح موقع وشوف الحزم
  3. فلتر حسب IP الراوتر
