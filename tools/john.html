John the Ripper

أداة كسر البصمات (Hashes)

يعني إيه John؟

John the Ripper هي أداة مفتوحة المصدر لكسر البصمات (Hashes). بتدعم أنواع كتير من البصمات (MD5, SHA1, SHA256, bcrypt, وغيرها). بتستخدم Dictionary Attack و Brute Force.

الأداة دي بتعتبر من أقدم وأشهر أدوات كسر الباسوردات — وبتدعم تشغيل على كل الأنظمة.

الاستخدامات

  • كسر باسوردات من ملفات مسربة
  • اختبار قوة الباسوردات
  • تحليل ملفات Linux (/etc/shadow)
  • كسر ملفات ZIP و RAR

التثبيت

# مش متوفر في Termux # على Kali Linux sudo apt install john # أو من GitHub git clone https://github.com/openwall/john.git

الأوامر الأساسية

1. كسر بصمة

john hash.txt

2. تحديد نوع البصمة

john --format=raw-md5 hash.txt

3. استخدام قاموس

john --wordlist=rockyou.txt hash.txt

4. عرض النتايج

john --show hash.txt

5. القوة الغاشمة

john --incremental hash.txt

6. كسر ملف ZIP

zip2john file.zip > hash.txt john hash.txt

الخيارات

  • --wordlist= — قاموس
  • --format= — نوع البصمة
  • --incremental — قوة غاشمة
  • --show — عرض النتايج
  • --rules — قواعد للقاموس
تحذير: استخدم John على بصماتك أو على بيئة تدريب. كسر بصمات حد تاني جريمة.

تمارين

  1. اعمل بصمة MD5 لباسوردك
  2. حطها في ملف وجرب John
  3. جرب John على TryHackMe
