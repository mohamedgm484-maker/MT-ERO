Gobuster

أداة البحث عن المسارات والملفات المخفية

يعني إيه Gobuster؟

Gobuster هي أداة مفتوحة المصدر بتدوّر على المسارات والملفات المخفية في مواقع الويب. بتستخدم قوائم جاهزة لتجريب مسارات شائعة.

الأداة دي بتعتبر من أسرع أدوات Directory Bruteforce — لأنها مكتوبة بـ Go.

الاستخدامات

  • اكتشاف صفحات مخفية
  • اكتشاف ملفات حساسة
  • اكتشاف Subdomains
  • اكتشاف Virtual Hosts

التثبيت

pkg install gobuster -y gobuster --help

الأوامر الأساسية

1. فحص مسارات

gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt

2. فحص Subdomains

gobuster dns -d example.com -w subdomains.txt

3. فحص Virtual Hosts

gobuster vhost -u http://example.com -w vhosts.txt
تحذير: متستخدمهاش على مواقع مش بتاعتك.

تمارين

  1. افحص موقعك
  2. جرب Gobuster على DVWA
  3. جرب أنواع الفحص المختلفة
