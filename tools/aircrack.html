Aircrack-ng

مجموعة أدوات لاختبار أمان شبكات الواي فاي

يعني إيه Aircrack-ng؟

Aircrack-ng هي مجموعة أدوات لاختبار أمان شبكات الواي فاي. بتستخدمها لتحليل حزم الشبكة، كسر باسوردات WEP و WPA/WPA2، واختبار قوة شبكتك.

الأداة دي بتعتبر الأشهر في مجال Wireless Security — وبتحتاج كارت شبكة يدعم Monitor Mode.

المكونات

  • airmon-ng: تشغيل Monitor Mode
  • airodump-ng: اعتراض الحزم
  • aireplay-ng: هجمات إعادة الإرسال
  • aircrack-ng: كسر الباسورد

التثبيت

# على Termux (محدود) pkg install aircrack-ng -y # على Kali Linux (كامل) sudo apt install aircrack-ng

الأوامر الأساسية

1. تشغيل Monitor Mode

airmon-ng start wlan0

2. اعتراض الحزم

airodump-ng wlan0mon

3. اعتراض شبكة معينة

airodump-ng -c 6 --bssid XX:XX:XX:XX:XX:XX -w capture wlan0mon

4. كسر الباسورد

aircrack-ng -w rockyou.txt capture-01.cap

5. إيقاف Monitor Mode

airmon-ng stop wlan0mon
تحذير: استخدم Aircrack-ng على شبكتك بس. اختراق شبكات الآخرين جريمة.
