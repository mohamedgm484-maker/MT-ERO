Hping3

أداة إرسال حزم TCP/IP مخصصة

يعني إيه Hping3؟

Hping3 هي أداة سطر أوامر لإرسال حزم TCP/IP مخصصة. بتستخدمها في تحليل الشبكات، Firewall Testing، واختبار أمان الشبكات.

الأداة دي بتعتبر بديل متقدم لـ ping العادي — وبتدعم TCP, UDP, ICMP.

الاستخدامات

  • اختبار Firewall
  • تحليل الشبكة
  • Port Scanning
  • DoS Testing (للأخلاقي)

التثبيت

# على Kali Linux sudo apt install hping3 # على Termux (محدود) pkg install hping3

الأوامر الأساسية

1. Ping TCP

hping3 -S -p 80 example.com

2. Ping ICMP

hping3 -1 example.com

3. Port Scan

hping3 -S -p ++1 example.com

4. Traceroute

hping3 -T -p 80 --traceroute example.com
خطر: Hping3 بتقدر تعمل DoS Attacks. متستخدمهاش على أي حاجة مش بتاعتك.

تمارين

  1. جرب Ping TCP
  2. اعمل Port Scan لجهازك
  3. اتعلم تحليل الشبكة
