FFUF

Fuzz Faster U Fool - أداة Fuzzing سريعة

يعني إيه FFUF؟

FFUF هي أداة مكتوبة بـ Go لـ Fuzzing مواقع الويب. بتستخدمها لاكتشاف المسارات، الباراميترات، والـ Subdomains بسرعة كبيرة.

الأداة دي بتعتبر من أسرع أدوات Fuzzing — لأنها بتشتغل بـ Multi-threading.

الاستخدامات

  • Directory Discovery
  • Parameter Fuzzing
  • Subdomain Fuzzing
  • Virtual Host Discovery

التثبيت

pkg install ffuf -y ffuf -h

الأوامر الأساسية

1. Directory Fuzzing

ffuf -w wordlist.txt -u http://example.com/FUZZ

2. Subdomain Fuzzing

ffuf -w subdomains.txt -u http://FUZZ.example.com

3. Parameter Fuzzing

ffuf -w params.txt -u http://example.com/page.php?FUZZ=test

4. فلترة النتايج

ffuf -w wordlist.txt -u http://example.com/FUZZ -fc 404
تحذير: استخدم FFUF على مواقعك إنت.

تمارين

  1. اكتشف مسارات موقعك
  2. جرب Parameter Fuzzing
  3. اتعلم Fuzzing
