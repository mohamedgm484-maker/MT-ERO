Recon-ng

إطار شامل لجمع المعلومات (OSINT)

يعني إيه Recon-ng؟

Recon-ng هو إطار مفتوح المصدر لجمع المعلومات (OSINT). بتستخدمه في مرحلة Recon — وبيعتمد على نظام Modules زي Metasploit.

الأداة دي بتعتبر الأشمل في مجالها — وفيها أكتر من 80 module لجمع المعلومات.

التثبيت

# على Kali Linux sudo apt install recon-ng # على Termux (صعب) pip install recon-ng

الأوامر الأساسية

1. تشغيل Recon-ng

recon-ng

2. بحث عن Modules

marketplace search

3. تثبيت Module

marketplace install recon/domains-hosts/hackertarget

4. استخدام Module

modules load recon/domains-hosts/hackertarget options set SOURCE example.com run
ملحوظة: Recon-ng بتجمع بيانات عامة بس.

تمارين

  2. جرب Modules مختلفة
  3. اتعلم OSINT
