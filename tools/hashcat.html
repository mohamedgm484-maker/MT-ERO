Hashcat

أسرع أداة كسر بصمات (تستخدم GPU)

يعني إيه Hashcat؟

Hashcat هي أسرع أداة كسر بصمات في العالم. بتستخدم كارت الشاشة (GPU) عشان توصل لسرعات خيالية (مليارات البصمات في الثانية). بتدعم أكتر من 300 نوع بصمة.

الأداة دي بتعتبر المعيار في مجال كسر الباسوردات — ومفيش أداة بتنافسها في السرعة.

المميزات

  • أسرع أداة كسر بصمات
  • بتستخدم GPU (مش CPU)
  • بتدعم 300+ نوع بصمة
  • Dictionary, Brute Force, Mask, Rules
  • بتشتغل على Windows, Linux, Mac

التثبيت

# مش هتشتغل على Termux (محتاج GPU) # على Kali Linux sudo apt install hashcat # على Windows حمّلها من https://hashcat.net/hashcat/

الأوامر الأساسية

1. Dictionary Attack

hashcat -m 0 -a 0 hash.txt rockyou.txt

-m 0: نوع MD5 | -a 0: Dictionary

2. Brute Force

hashcat -m 0 -a 3 hash.txt ?a?a?a?a

-a 3: Brute Force | ?a: كل الرموز

3. Mask Attack

hashcat -m 0 -a 3 hash.txt ?u?l?l?l?d?d?d?d

?u: حرف كبير | ?l: صغير | ?d: رقم

4. عرض النتايج

hashcat -m 0 hash.txt --show

أنواع البصمات

  • -m 0 — MD5
  • -m 100 — SHA1
  • -m 1400 — SHA256
  • -m 1700 — SHA512
  • -m 1000 — NTLM
  • -m 3200 — bcrypt
  • -m 2500 — WPA/WPA2

أوضاع الهجوم

  • -a 0 — Dictionary
  • -a 1 — Combination
  • -a 3 — Brute Force / Mask
  • -a 6 — Hybrid Wordlist + Mask
  • -a 7 — Hybrid Mask + Wordlist
السرعة: مع RTX 4090، Hashcat بيكسر 100+ مليار MD5/ثانية. مع CPU، بيكسر 100 مليون/ثانية.
تحذير: استخدم Hashcat على بصماتك أو بيئة تدريب. كسر بصمات حد تاني جريمة.

تمارين

  1. اعمل بصمة MD5 لباسورد ضعيف
  2. جرب Hashcat عليها
  3. جرب أنواع بصمات مختلفة
  4. جرب Mask Attack
