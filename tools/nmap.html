Nmap

أداة فحص الشبكات الأشهر في العالم

يعني إيه Nmap؟

Nmap (Network Mapper) هي أداة مفتوحة المصدر لفحص الشبكات واكتشاف البورتات المفتوحة والخدمات الشغالة. بتستخدمها في اختبار الاختراق الأخلاقي عشان تعرف نقاط الدخول المحتملة. الأداة دي بتعتبر الأساس في أي عملية اختبار اختراق — لأنها بتديك صورة كاملة عن الشبكة اللي بتفحصها.

Nmap بتشتغل على كل أنظمة التشغيل — Linux و Windows و macOS. وبتدعم IPv6 وعدد كبير من تقنيات الفحص المتقدمة. المميز فيها إنها سريعة جداً وبتقدر تفحص آلاف الأجهزة في وقت قصير.

الاستخدامات

  • اكتشاف الأجهزة المتصلة بالشبكة
  • معرفة البورتات المفتوحة والمقفولة
  • كشف الخدمات وإصداراتها
  • كشف نظام التشغيل
  • فحص الثغرات المعروفة
  • مراقبة الشبكة

التثبيت

# على Termux pkg install nmap -y # التأكد nmap --version

الأوامر الأساسية

1. فحص أساسي

nmap scanme.nmap.org

بيفحص أول 1000 بورت شائع.

2. كشف الخدمات

nmap -sV scanme.nmap.org

بيعرف نوع الخدمة والإصدار.

3. كشف نظام التشغيل

nmap -O scanme.nmap.org

4. فحص الشبكة كاملة

nmap -sn 192.168.1.0/24

5. فحص بورتات محددة

nmap -p 22,80,443 192.168.1.1

6. فحص سريع

nmap -T4 -F 192.168.1.1

7. فحص كل حاجة

nmap -A -v 192.168.1.1

شرح النتائج

PORT STATE SERVICE VERSION 22/tcp open ssh OpenSSH 8.2 80/tcp open http nginx 1.18.0 443/tcp open ssl/https nginx 1.18.0
  • PORT: رقم البورت
  • STATE: open / closed / filtered
  • SERVICE: الخدمة
  • VERSION: الإصدار

حالات البورتات

  • open: البورت مفتوح ومستقبل اتصالات
  • closed: مقفول لكن السيرفر موجود
  • filtered: فيه فايروول بيمنع
  • unfiltered: مش متأكد
تحذير: متفحصش شبكات مش بتاعتك. Nmap بيسجل في اللوجات.

تمارين

  1. افحص scanme.nmap.org
  2. افحص شبكتك المحلية
  3. اعرف إصدار الخدمات على الراوتر
  4. دوّر على بورت 22 في شبكتك
