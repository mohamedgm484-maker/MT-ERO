Burp Suite

أداة اعتراض وتحليل طلبات HTTP/HTTPS

يعني إيه Burp Suite؟

Burp Suite هي أداة اختبار اختراق لتطبيقات الويب. بتشتغل كـ Proxy بين المتصفح والسيرفر، بتعترض كل الطلبات والردود وتخليك تعدل فيها وتحللها.

الأداة دي بتعتبر الأهم في مجال Web Application Security — وأي مختبر اختراق محترف لازم يتقنها. وبتستخدمها شركات كتير في اختبار مواقعها.

المكونات

  • Proxy: اعتراض الطلبات
  • Repeater: إعادة إرسال الطلبات
  • Intruder: هجمات أوتوماتيكية
  • Scanner: فحص الثغرات (Pro)
  • Decoder: تشفير/فك تشفير
  • Comparer: مقارنة

التثبيت

# Burp مش بيشتغل على Termux # على Kali Linux (مثبت أصلاً) burpsuite # أو حمّله من https://portswigger.net/burp/communitydownload

الخطوات

1. تشغيل Burp

افتح Burp Suite → Temporary Project → Start Burp

2. إعداد الـ Proxy

Proxy → Options → تأكد إن البورت 8080

3. إعداد المتصفح

في المتصفح: اضبط الـ Proxy على 127.0.0.1:8080

4. تفعيل شهادة SSL

افتح http://burp → تحميل الشهادة → إضافتها للمتصفح

5. اعتراض الطلبات

Proxy → Intercept → On

6. تحليل الطلبات

شوف الطلبات في HTTP History

المميزات الرئيسية

  • Intercept: اعتراض وتعديل الطلبات
  • Repeater: تجربة الطلبات مرات كتير
  • Intruder: هجمات Brute Force
  • Decoder: فك تشفير Base64, URL
  • Comparer: مقارنة ردود
ملحوظة: Burp Suite Community Edition مجاني. Pro بفلوس (399$/سنة).
