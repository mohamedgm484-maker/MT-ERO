C++

لغة قوية للأنظمة والألعاب

يعني إيه C++؟

C++ هي لغة برمجة عالية الأداء، بتستخدم في الأنظمة، الألعاب، التطبيقات اللي محتاجة سرعة عالية. بتعتبر من أقوى اللغات في العالم.

بتستخدمها شركات كتير زي Microsoft و Adobe و Google — وكمان في الأمن السيبراني لفهم الذاكرة والـ Buffer Overflow.

استخدامات C++

  • أنظمة التشغيل (Windows, Linux)
  • الألعاب (Unreal Engine)
  • المتصفحات (Chrome, Firefox)
  • الأدوات الأمنية
  • الأنظمة المدمجة
  • البرامج اللي محتاجة أداء عالي

التثبيت

pkg install clang -y # اختبار clang++ --version

الأساسيات

1. البرنامج الأول

#include <iostream> using namespace std; int main() { cout << "Hello World" << endl; return 0; }

2. المتغيرات

int age = 25; float salary = 5000.50; double pi = 3.14159; char letter = 'A'; string name = "Ahmed"; bool is_hacker = true; cout << name << endl; cout << age << endl;

3. المدخلات

int age; cout << "اكتب عمرك: "; cin >> age; string name; cout << "اكتب اسمك: "; cin >> name; cout << "أهلاً " << name << endl;

4. الشروط

int age = 20; if (age >= 18) { cout << "بالغ" << endl; } else if (age >= 13) { cout << "مراهق" << endl; } else { cout << "طفل" << endl; }

5. الحلقات

// for for (int i = 0; i < 5; i++) { cout << i << endl; } // while int count = 0; while (count < 5) { cout << count << endl; count++; }

6. الدوال

int add(int a, int b) { return a + b; } void greet(string name) { cout << "أهلاً " << name << endl; } int main() { cout << add(5, 3) << endl; greet("Ahmed"); return 0; }

7. المصفوفات

int numbers[5] = {1, 2, 3, 4, 5}; for (int i = 0; i < 5; i++) { cout << numbers[i] << endl; }

8. المؤشرات (Pointers)

int x = 10; int* ptr = &x; cout << "القيمة: " << x << endl; cout << "العنوان: " << ptr << endl; cout << "القيمة من المؤشر: " << *ptr << endl;
