Bash

لغة الطرفية الأساسية في Linux

يعني إيه Bash؟

Bash (Bourne Again SHell) هي لغة برمجة نصية (Shell Scripting) بتستخدم في Linux و macOS. بتستخدمها في الأتمتة، إدارة الأنظمة، وكتابة السكربتات.

بتعتبر أساسية في الأمن السيبراني — لأن كل أدوات الاختراق بتشتغل من الطرفية.

الأساسيات

1. أول سكربت

#!/bin/bash echo "Hello World" # تصريح chmod +x script.sh ./script.sh

2. المتغيرات

name="Ahmed" age=25 echo "أهلاً $name" echo "عمرك $age"

3. المدخلات

read -p "اكتب اسمك: " name echo "أهلاً $name"

4. الشروط

if [ $age -gt 18 ]; then echo "بالغ" elif [ $age -gt 13 ]; then echo "مراهق" else echo "طفل" fi

5. الحلقات

# for for i in {1..5}; do echo "رقم: $i" done # while count=0 while [ $count -lt 5 ]; do echo $count ((count++)) done

6. الدوال

greet() { echo "أهلاً $1" } greet "Ahmed"

7. معالجة الملفات

# قراءة while read line; do echo $line done < file.txt # كتابة echo "Hello" > file.txt # إضافة echo "World" >> file.txt

استخدامات في الأمن السيبراني

1. Automated Scanning

#!/bin/bash for ip in 192.168.1.{1..254}; do ping -c 1 -W 1 $ip > /dev/null && echo "$ip up" done

2. Backup Script

#!/bin/bash DATE=$(date +%Y-%m-%d) tar -czf backup-$DATE.tar.gz /home/user
