C#

لغة Microsoft لتطوير التطبيقات

يعني إيه C#؟

C# (C-Sharp) هي لغة برمجة من Microsoft، بتستخدم في تطوير تطبيقات الويندوز، الألعاب (Unity)، وتطبيقات الويب.

بتعتبر اللغة الأساسية في بيئة .NET — وبتستخدمها شركات كتير في التطبيقات الكبيرة.

الأساسيات

1. البرنامج الأول

using System; class Program { static void Main() { Console.WriteLine("Hello World"); } }

2. المتغيرات

string name = "Ahmed"; int age = 25; double salary = 5000.50; bool isHacker = true; char letter = 'A'; Console.WriteLine(name); Console.WriteLine(age);

3. الشروط

int age = 20; if (age >= 18) { Console.WriteLine("بالغ"); } else if (age >= 13) { Console.WriteLine("مراهق"); } else { Console.WriteLine("طفل"); }

4. الحلقات

for (int i = 0; i < 5; i++) { Console.WriteLine(i); } int count = 0; while (count < 5) { Console.WriteLine(count); count++; } string[] tools = {"nmap", "hydra"}; foreach (string tool in tools) { Console.WriteLine(tool); }

5. الدوال

static int Add(int a, int b) { return a + b; } static void Greet(string name) { Console.WriteLine($"أهلاً {name}"); } static void Main() { Console.WriteLine(Add(5, 3)); Greet("Ahmed"); }

6. الكلاسات

class User { public string Name { get; set; } public int Age { get; set; } public User(string name, int age) { Name = name; Age = age; } public void Greet() { Console.WriteLine($"أهلاً {Name}"); } } class Program { static void Main() { User user = new User("Ahmed", 25); user.Greet(); } }
