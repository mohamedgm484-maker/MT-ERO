HTML

هيكل صفحات الويب

يعني إيه HTML؟

HTML (HyperText Markup Language) هي لغة توصيف النص التشعبي. بتستخدمها لبناء هيكل صفحات الويب — بتحدد العناوين، الفقرات، الصور، الروابط، وغيرها.

HTML هي أساس أي موقع — وأي حد بيتعلم برمجة ويب لازم يبدأ بيها. وهي مش لغة برمجة (مفيهاش منطق) بس لغة توصيف.

ليه HTML مهمة؟

  • الأساس في تطوير الويب
  • سهلة جداً — أي حد يتعلمها في يوم
  • بتشتغل على كل المتصفحات
  • معاها CSS و JavaScript بتعمل مواقع كاملة

الأساسيات

1. هيكل الصفحة

<!DOCTYPE html> <html lang="ar" dir="rtl"> <head> <meta charset="UTF-8"> <title>عنوان الصفحة</title> </head> <body> <h1>أهلاً بيك</h1> </body> </html>

2. العناوين

<h1>عنوان رئيسي</h1> <h2>عنوان فرعي</h2> <h3>عنوان أصغر</h3> <h4>عنوان أصغر</h4> <h5>عنوان أصغر</h5> <h6>عنوان أصغر</h6>

3. الفقرات

<p>دي فقرة نص عادية</p> <br> <!-- سطر جديد --> <hr> <!-- خط فاصل -->

4. الروابط والصور

<a href="https://example.com">اضغط هنا</a> <a href="https://example.com" target="_blank">فتح في تاب جديد</a> <img src="image.jpg" alt="وصف الصورة">

5. القوائم

<!-- قائمة مرتبة --> <ol> <li>العنصر الأول</li> <li>العنصر الثاني</li> </ol> <!-- قائمة غير مرتبة --> <ul> <li>عنصر</li> <li>عنصر</li> </ul>

6. الجداول

<table> <tr> <th>الاسم</th> <th>العمر</th> </tr> <tr> <td>أحمد</td> <td>25</td> </tr> </table>

7. النماذج (Forms)

<form action="/submit" method="POST"> <input type="text" name="username" placeholder="الاسم"> <input type="email" name="email" placeholder="الإيميل"> <input type="password" name="password" placeholder="الباسورد"> <input type="submit" value="إرسال"> </form>

8. الوسوم الدلالية (Semantic Tags)

<header>الرأس</header> <nav>القائمة</nav> <main>المحتوى الرئيسي</main> <section>قسم</section> <article>مقال</article> <aside>جانبي</aside> <footer>التذييل</footer>
