Elixir

لغة Functional حديثة

يعني إيه Elixir؟

Elixir هي لغة برمجة Functional حديثة، بتشتغل على Erlang VM. بتتميز بالتوازي والأداء العالي والتسامح مع الأخطاء.

بتستخدمها شركات كتير زي Discord و Pinterest في الأنظمة اللي محتاجة Scale كبير.

الأساسيات

1. البرنامج الأول

IO.puts("Hello World")

2. المتغيرات

name = "Ahmed" age = 25 salary = 5000.50 IO.puts("أهلاً #{name}") IO.puts("عمرك #{age}")

3. الشروط

age = 20 if age >= 18 do IO.puts("بالغ") else IO.puts("طفل") end # Case case age do a when a >= 18 -> IO.puts("بالغ") _ -> IO.puts("طفل") end

4. الحلقات والـ Recursion

# Enum Enum.each(1..5, fn i -> IO.puts(i) end) Enum.map(1..5, fn i -> i * 2 end) # Recursion defmodule Counter do def count(0), do: nil def count(n) do IO.puts(n) count(n - 1) end end

5. الدوال

defmodule Greet do def hello(name) do "أهلاً #{name}" end def add(a, b), do: a + b end IO.puts(Greet.hello("Ahmed")) IO.puts(Greet.add(5, 3))

6. Modules

defmodule User do defstruct name: "", age: 0 def greet(%User{name: name}) do "أهلاً #{name}" end end user = %User{name: "Ahmed", age: 25} IO.puts(User.greet(user))
