MATLAB

لغة الحسابات الهندسية

يعني إيه MATLAB؟

MATLAB هي بيئة حوسبة ولغة برمجة من MathWorks، بتستخدم في الحسابات الرياضية، التحليل العددي، ومعالجة الصور.

بتستخدمها الجامعات والشركات في الهندسة والعلوم — وفي الأمن السيبراني بتستخدم في تحليل الإشارات.

الأساسيات

1. المتغيرات

name = 'Ahmed'; age = 25; salary = 5000.50; is_hacker = true; disp(['أهلاً ' name]) disp(age)

2. المصفوفات

numbers = [1, 2, 3, 4, 5]; % Matrix matrix = [1, 2, 3; 4, 5, 6; 7, 8, 9]; % Range x = 1:10; disp(numbers) disp(matrix)

3. الشروط

age = 20; if age >= 18 disp('بالغ') elseif age >= 13 disp('مراهق') else disp('طفل') end

4. الحلقات

% For for i = 0:4 disp(i) end % While count = 0; while count < 5 disp(count) count = count + 1; end

5. الدوال

function result = add(a, b) result = a + b; end function greet(name) disp(['أهلاً ' name]) end add(5, 3) greet('Ahmed')

6. الرسم البياني

x = 0:0.1:10; y = sin(x); plot(x, y); xlabel('X'); ylabel('Y'); title('Sine Wave'); grid on;
