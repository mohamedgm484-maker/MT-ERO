JavaScript

لغة الويب الأساسية — Frontend و Backend

يعني إيه JavaScript؟

JavaScript هي لغة برمجة بتشتغل في المتصفح والسيرفر. بتستخدمها لعمل صفحات ويب تفاعلية، تطبيقات ويب كاملة، وتطبيقات موبايل.

بتعتبر اللغة الأكتر استخداماً في العالم — وكل موقع بيستخدمها. وكمان بتستخدمها في الأمن السيبراني لفهم XSS وCSRF.

استخدامات JavaScript

  • تطوير الويب (Frontend)
  • تطوير السيرفرات (Node.js)
  • تطبيقات الموبايل (React Native)
  • تطبيقات الديسكتوب (Electron)
  • الألعاب (Phaser)
  • الأمن السيبراني (XSS Analysis)

الأساسيات

1. المتغيرات

// let - متغير قابل للتغيير let name = "Ahmed"; // const - ثابت const PI = 3.14; // var - قديم (متستخدمهوش) var old = "old"; console.log(name); console.log(PI);

2. أنواع البيانات

let string = "Hello"; let number = 42; let decimal = 3.14; let boolean = true; let array = [1, 2, 3]; let object = {name: "Ahmed", age: 25}; let nothing = null; let undef = undefined;

3. الشروط

let password = "123456"; if (password.length < 8) { console.log("ضعيف"); } else if (password.length < 12) { console.log("متوسط"); } else { console.log("قوي"); }

4. الحلقات

// for for (let i = 0; i < 5; i++) { console.log(i); } // while let count = 0; while (count < 5) { console.log(count); count++; } // forEach let tools = ["nmap", "hydra"]; tools.forEach(tool => console.log(tool));

5. الدوال

// دالة عادية function greet(name) { return "أهلاً " + name; } // Arrow Function const greet2 = (name) => "أهلاً " + name; console.log(greet("Ahmed")); console.log(greet2("Mohamed"));

6. الـ DOM

// اختيار عنصر const element = document.getElementById("myId"); const elements = document.querySelectorAll(".myClass"); // تغيير النص element.textContent = "نص جديد"; // تغيير الـ HTML element.innerHTML = "<b>نص عريض</b>"; // تغيير الستايل element.style.color = "red"; // إضافة حدث element.addEventListener("click", () => { alert("تم الضغط"); });

7. Promises و Async/Await

// Promise fetch("https://api.github.com") .then(response => response.json()) .then(data => console.log(data)); // Async/Await async function getData() { const response = await fetch("https://api.github.com"); const data = await response.json(); console.log(data); } getData();

مكتبات مهمة

1. React

import React from 'react'; function App() { const [count, setCount] = React.useState(0); return ( <div> <h1>{count}</h1> <button onClick={() => setCount(count + 1)}> زيادة </button> </div> ); }

2. Node.js

const http = require('http'); const server = http.createServer((req, res) => { res.writeHead(200, {'Content-Type': 'text/plain'}); res.end('Hello World'); }); server.listen(3000);

3. Express.js

const express = require('express'); const app = express(); app.get('/', (req, res) => { res.send('Hello World'); }); app.listen(3000);
