Go (Golang)

لغة سريعة وبسيطة من Google

يعني إيه Go؟

Go (Golang) هي لغة برمجة مفتوحة المصدر من Google. بتتميز بالسرعة والبساطة والكفاءة في التعامل مع الأنظمة المتوازية.

بتستخدمها شركات كتير زي Google و Uber و Docker. وفي الأمن السيبراني، أدوات كتير مكتوبة بـ Go (زي ffuf, nuclei).

استخدامات Go

  • تطوير السيرفرات
  • أدوات CLI
  • الأدوات الأمنية
  • Cloud Services
  • Blockchain

الأساسيات

1. البرنامج الأول

package main import "fmt" func main() { fmt.Println("Hello World") }

2. المتغيرات

var name string = "Ahmed" var age int = 25 var salary float64 = 5000.50 var isHacker bool = true // Short declaration city := "Cairo" fmt.Println(name, age, salary, isHacker, city)

3. الشروط

age := 20 if age >= 18 { fmt.Println("بالغ") } else if age >= 13 { fmt.Println("مراهق") } else { fmt.Println("طفل") }

4. الحلقات

for i := 0; i < 5; i++ { fmt.Println(i) } // While style count := 0 for count < 5 { fmt.Println(count) count++ } // Range tools := []string{"nmap", "hydra"} for i, tool := range tools { fmt.Println(i, tool) }

5. الدوال

func greet(name string) string { return "أهلاً " + name } func add(a, b int) int { return a + b } // Multiple returns func divide(a, b float64) (float64, error) { if b == 0 { return 0, fmt.Errorf("قسمة على صفر") } return a / b, nil }

6. Structs

type User struct { Name string Age int } func main() { user := User{Name: "Ahmed", Age: 25} fmt.Println(user.Name) fmt.Println(user.Age) }

7. Goroutines

func task(id int) { fmt.Println("Task", id) } func main() { for i := 1; i <= 5; i++ { go task(i) } time.Sleep(time.Second) }
