Rust

لغة آمنة وسريعة للأنظمة

يعني إيه Rust؟

Rust هي لغة برمجة أنظمة (Systems Programming) مفتوحة المصدر، بتتميز بالأمان والسرعة. بتستخدم بدل C++ في مشاريع كتير.

بتعتبر الأكثر أماناً في إدارة الذاكرة — وبتستخدمها شركات زي Mozilla و Microsoft و Dropbox.

استخدامات Rust

  • أنظمة التشغيل
  • أدوات CLI
  • WebAssembly
  • Blockchain
  • الألعاب
  • الأدوات الأمنية

الأساسيات

1. البرنامج الأول

fn main() { println!("Hello World"); }

2. المتغيرات

// Immutable let name = "Ahmed"; // Mutable let mut age = 25; age = 26; // Types let salary: f64 = 5000.50; let is_hacker: bool = true; println!("{}", name);

3. الشروط

let age = 20; if age >= 18 { println!("بالغ"); } else if age >= 13 { println!("مراهق"); } else { println!("طفل"); }

4. الحلقات

for i in 0..5 { println!("{}", i); } let mut count = 0; while count < 5 { println!("{}", count); count += 1; } let tools = vec!["nmap", "hydra"]; for tool in &tools { println!("{}", tool); }

5. الدوال

fn greet(name: &str) -> String { format!("أهلاً {}", name) } fn add(a: i32, b: i32) -> i32 { a + b } fn main() { println!("{}", greet("Ahmed")); println!("{}", add(5, 3)); }

6. Ownership

let s1 = String::from("Hello"); let s2 = s1; // s1 moved to s2 // println!("{}", s1); // خطأ! // Cloning let s3 = String::from("World"); let s4 = s3.clone();

7. Structs

struct User { name: String, age: u32, } fn main() { let user = User { name: String::from("Ahmed"), age: 25, }; println!("{}", user.name); println!("{}", user.age); }
