Scala

لغة قوية لمعالجة البيانات الكبيرة

يعني إيه Scala؟

Scala هي لغة برمجة تجمع بين OOP و Functional Programming. بتشتغل على JVM — وبتستخدم في Big Data و Backend.

بتعتبر اللغة الأساسية لـ Apache Spark — وبتستخدمها شركات كتير زي Twitter و Netflix.

الأساسيات

1. المتغيرات

// Immutable val name = "Ahmed" // Mutable var age = 25 age = 26 val salary: Double = 5000.50 val isHacker: Boolean = true println(name) println(age)

2. الشروط

val age = 20 if (age >= 18) { println("بالغ") } else if (age >= 13) { println("مراهق") } else { println("طفل") } // كتعبير val status = if (age >= 18) "بالغ" else "طفل"

3. الحلقات

for (i <- 0 until 5) { println(i) } val tools = List("nmap", "hydra") tools.foreach(tool => println(tool)) // Functional val doubled = (1 to 5).map(_ * 2)

4. الدوال

def greet(name: String): String = { s"أهلاً $name" } def add(a: Int, b: Int): Int = a + b println(greet("Ahmed")) println(add(5, 3))

5. Classes و Case Classes

class User(val name: String, val age: Int) { def greet(): String = s"أهلاً $name" } case class Product(name: String, price: Double) val user = new User("Ahmed", 25) println(user.greet()) val p = Product("Laptop", 5000.0) println(p.name)
