SQL

لغة قواعد البيانات

يعني إيه SQL؟

SQL (Structured Query Language) هي لغة إدارة قواعد البيانات العلائقية. بتستخدمها للتعامل مع البيانات — إضافة، تعديل، حذف، واستعلام.

بتعتبر أساسية في الأمن السيبراني — عشان تفهم SQL Injection لازم تكون فاهم SQL كويس.

أنواع قواعد البيانات

  • MySQL (الأشهر)
  • PostgreSQL
  • SQLite
  • Oracle
  • SQL Server

الأساسيات

1. إنشاء قاعدة بيانات

CREATE DATABASE mydb; USE mydb;

2. إنشاء جدول

CREATE TABLE users ( id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(100), email VARCHAR(100), age INT );

3. إدخال بيانات

INSERT INTO users (name, email, age) VALUES ('Ahmed', 'ahmed@test.com', 25); INSERT INTO users (name, email, age) VALUES ('Mohamed', 'mo@test.com', 30), ('Sara', 'sara@test.com', 22);

4. استعلام البيانات

-- كل البيانات SELECT * FROM users; -- أعمدة محددة SELECT name, email FROM users; -- مع شرط SELECT * FROM users WHERE age > 20; -- ترتيب SELECT * FROM users ORDER BY age DESC; -- حد SELECT * FROM users LIMIT 10; -- بحث SELECT * FROM users WHERE name LIKE '%Ahmed%';

5. تعديل البيانات

UPDATE users SET age = 26 WHERE name = 'Ahmed';

6. حذف البيانات

DELETE FROM users WHERE id = 1;

7. الدوال التجميعية

SELECT COUNT(*) FROM users; SELECT AVG(age) FROM users; SELECT MAX(age) FROM users; SELECT MIN(age) FROM users; SELECT SUM(age) FROM users;

8. GROUP BY

SELECT age, COUNT(*) as count FROM users GROUP BY age;

9. JOIN

-- INNER JOIN SELECT users.name, orders.product FROM users INNER JOIN orders ON users.id = orders.user_id; -- LEFT JOIN SELECT users.name, orders.product FROM users LEFT JOIN orders ON users.id = orders.user_id;

SQL Injection

SQL Injection هي ثغرة أمنية بتحصل لما الموقع بياخد بيانات من المستخدم وبيحطها في استعلام SQL من غير تأمين.

-- استعلام عادي SELECT * FROM users WHERE username = 'admin' AND password = '123'; -- SQL Injection SELECT * FROM users WHERE username = 'admin' OR '1'='1' --' AND password = '';

خطة التعلم

المستوى 1: المبتدئ (شهر)

  • SELECT, INSERT, UPDATE, DELETE
  • WHERE, ORDER BY, LIMIT
  • الدوال التجميعية

المستوى 2: المتوسط (شهرين)

  • JOINs
  • Subqueries
  • Indexes
  • Views

المستوى 3: الاحتراف (3 شهور)

  • Stored Procedures
  • Triggers
  • Optimization
  • NoSQL
