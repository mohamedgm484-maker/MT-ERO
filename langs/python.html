Python

اللغة الأساسية في الأمن السيبراني

يعني إيه Python؟

Python هي لغة برمجة عالية المستوى، سهلة التعلم، وقوية جداً. بتستخدمها في الأمن السيبراني عشان تكتب أدوات، تسكربت هجمات، تحلل بيانات، وتعمل أتمتة للمهام المتكررة.

بتعتبر اللغة رقم 1 في مجال الأمن السيبراني — لأنها سهلة وبسيطة وفيها مكتبات جاهزة كتير بتوفر وقت كبير. وكمان بتستخدمها شركات كتير زي Google و NASA و Intel.

ليه Python مهمة؟

  • سهلة التعلم — مناسبة للمبتدئين
  • مكتبات كتير جاهزة (requests, scapy, hashlib)
  • بتشتغل على كل الأنظمة
  • أدوات كتير مكتوبة بيها (SQLMap, theHarvester)
  • سريعة في التطوير
  • مجتمع ضخم
  • بتدعم الذكاء الاصطناعي

استخدامات Python

  • كتابة أدوات الأمن السيبراني
  • أتمتة المهام المتكررة
  • تحليل البيانات
  • تطوير الويب (Django, Flask)
  • الذكاء الاصطناعي (TensorFlow, PyTorch)
  • علم البيانات
  • كتابة سكربتات النظام

مكتبات مهمة للأمن السيبراني

1. hashlib — التشفير

import hashlib password = "123456" md5 = hashlib.md5(password.encode()).hexdigest() sha256 = hashlib.sha256(password.encode()).hexdigest() print(f"MD5: {md5}") print(f"SHA256: {sha256}")

2. requests — HTTP

import requests # GET Request response = requests.get("https://api.github.com") print(response.status_code) print(response.json()) # POST Request data = {"username": "admin", "password": "123"} response = requests.post("https://example.com/login", data=data)

3. socket — الشبكات

import socket s = socket.socket(socket.AF_INET, socket.SOCK_STREAM) s.settimeout(2) target = "scanme.nmap.org" port = 80 result = s.connect_ex((target, port)) if result == 0: print(f"البورت {port} مفتوح") else: print(f"البورت {port} مقفول") s.close()

4. os — النظام

أداة كاملة: Port Scanner

import socket import sys from datetime import datetime def scan_port(target, port): try: s = socket.socket(socket.AF_INET, socket.SOCK_STREAM) s.settimeout(1) result = s.connect_ex((target, port)) s.close() return result == 0 except: return False def scan_target(target, start=1, end=1024): print(f"فحص {target}") print(f"الوقت: {datetime.now()}") open_ports = [] for port in range(start, end + 1): if scan_port(target, port): print(f"البورت {port} مفتوح") open_ports.append(port) print(f"\nالنتيجة: {len(open_ports)} بورت مفتوح") return open_ports if __name__ == "__main__": target = input("اكتب الهدف: ") scan_target(target)
