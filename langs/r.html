R

لغة تحليل البيانات والإحصاء

يعني إيه R؟

R هي لغة برمجة وبيئة حوسبة إحصائية. بتستخدم في تحليل البيانات، الإحصاء، وعلوم البيانات.

بتعتبر اللغة رقم 1 في الأكاديميا والإحصاء — وبتستخدمها شركات كتير في Data Science.

استخدامات R

  • تحليل البيانات
  • الإحصاء
  • Machine Learning
  • Data Visualization
  • تحليل البيانات الأمنية

الأساسيات

1. المتغيرات

name <- "Ahmed" age <- 25 salary <- 5000.50 is_hacker <- TRUE print(name) print(age)

2. أنواع البيانات

numbers <- c(1, 2, 3, 4, 5) names <- c("Ahmed", "Mohamed", "Sara") # Vector x <- 1:10 # List person <- list(name = "Ahmed", age = 25) # Data Frame df <- data.frame( name = c("Ahmed", "Sara"), age = c(25, 22) ) print(df)

3. الشروط

age <- 20 if (age >= 18) { print("بالغ") } else if (age >= 13) { print("مراهق") } else { print("طفل") }

4. الحلقات

# For for (i in 1:5) { print(i) } # While count <- 0 while (count < 5) { print(count) count <- count + 1 } # Apply numbers <- 1:5 sapply(numbers, function(x) x * 2)

5. الدوال

greet <- function(name) { paste("أهلاً", name) } add <- function(a, b) { a + b } print(greet("Ahmed")) print(add(5, 3))

6. تحليل البيانات

df <- data.frame( name = c("Ahmed", "Sara", "Mohamed"), age = c(25, 22, 30) ) # عرض البيانات print(df) # ملخص summary(df) # فلترة df[df$age > 24, ] # إحصاء mean(df$age) median(df$age) max(df$age) min(df$age)
