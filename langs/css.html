CSS

تصميم وتنسيق صفحات الويب

يعني إيه CSS؟

CSS (Cascading Style Sheets) هي لغة تنسيق صفحات الويب. بتستخدمها لتحديد الألوان، الخطوط، الأحجام، والتصميم العام للصفحة.

CSS بتعتبر أساس التصميم في الويب — ومن غيرها الصفحة تبقى نص عادي من غير أي جمال.

ليه CSS مهمة؟

  • بتخلي الموقع شكله حلو
  • بتخلي الموقع متجاوب (Responsive)
  • بتشتغل على كل المتصفحات
  • بتوفر وقت (بتعدل تصميم كامل من مكان واحد)

الأساسيات

1. طريقة الاستخدام

/* Inline */ <p style="color: red;">نص أحمر</p> /* Internal */ <style> p { color: red; } </style> /* External (الأفضل) */ <link rel="stylesheet" href="style.css">

2. المحددات (Selectors)

/* Element */ p { color: red; } /* Class */ .my-class { color: blue; } /* ID */ #my-id { color: green; } /* Descendant */ div p { color: yellow; } /* Child */ div > p { color: orange; }

3. الألوان

color: red; /* الاسم */ color: #ff0000; /* Hex */ color: rgb(255, 0, 0); /* RGB */ color: rgba(255, 0, 0, 0.5); /* RGB مع شفافية */ color: hsl(0, 100%, 50%); /* HSL */

4. الخطوط

font-family: Arial, sans-serif; font-size: 16px; font-weight: bold; font-style: italic; line-height: 1.5; text-align: center;

5. Box Model

.box { width: 200px; height: 100px; padding: 20px; /* داخلي */ border: 2px solid red; margin: 10px; /* خارجي */ }

6. Flexbox

.container { display: flex; justify-content: center; /* أفقي */ align-items: center; /* عمودي */ gap: 20px; flex-wrap: wrap; }

7. Grid

.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

8. Media Queries

/* موبايل */ @media (max-width: 768px) { body { font-size: 14px; } } /* تابلت */ @media (min-width: 769px) and (max-width: 1024px) { body { font-size: 16px; } }

9. الحركات (Animations)

/* Transition */ .box { transition: all 0.3s ease; } .box:hover { transform: scale(1.1); } /* Animation */ @keyframes pulse { 0%, 100% { opacity: 1; } 50% { opacity: 0.5; } } .element { animation: pulse 2s infinite; }
