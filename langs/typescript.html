TypeScript

JavaScript مع أنواع

يعني إيه TypeScript؟

TypeScript هي لغة برمجة من Microsoft، بتبني على JavaScript وبتحط عليها نظام أنواع (Types). بتستخدم في تطوير المشاريع الكبيرة.

بتعتبر النسخة المتطورة من JavaScript — وبتستخدمها شركات كتير زي Google و Airbnb و Slack.

التثبيت

npm install -g typescript tsc --version

الأساسيات

1. الأنواع

let name: string = "Ahmed"; let age: number = 25; let isHacker: boolean = true; // Array let tools: string[] = ["nmap", "hydra"]; let numbers: number[] = [1, 2, 3]; // Any let anything: any = "hello"; anything = 42; // Union let id: string | number = "abc"; id = 123;

2. Interfaces

interface User { name: string; age: number; email?: string; // Optional } const user: User = { name: "Ahmed", age: 25 };

3. Types

type Status = "active" | "inactive" | "pending"; type Product = { name: string; price: number; }; const p: Product = { name: "Laptop", price: 5000 };

4. Functions

function greet(name: string): string { return "أهلاً " + name; } const add = (a: number, b: number): number => a + b; // Optional params function buildName(first: string, last?: string): string { return last ? first + " " + last : first; }

5. Generics

function identity<T>(arg: T): T { return arg; } let output = identity<string>("hello"); let output2 = identity<number>(42); // مع Arrays function getFirst<T>(arr: T[]): T { return arr[0]; }
