Ruby

لغة برمجة أنيقة وسهلة

يعني إيه Ruby؟

Ruby هي لغة برمجة ديناميكية، مفتوحة المصدر، ومركزة على البساطة والإنتاجية. بتستخدم في تطوير الويب (Ruby on Rails) وكتابة السكربتات.

بتعتبر من أجمل اللغات في القراءة — وكودها قريب من اللغة الإنجليزية.

استخدامات Ruby

  • تطوير الويب (Rails)
  • كتابة سكربتات
  • الأتمتة
  • أدوات الأمن السيبراني (Metasploit مكتوب بـ Ruby)

الأساسيات

1. البرنامج الأول

puts "Hello World"

2. المتغيرات

name = "Ahmed" age = 25 salary = 5000.50 is_hacker = true puts "أهلاً #{name}" puts "عمرك #{age}"

3. الشروط

age = 20 if age >= 18 puts "بالغ" elsif age >= 13 puts "مراهق" else puts "طفل" end

4. الحلقات

# for for i in 0...5 puts i end # each tools = ["nmap", "hydra"] tools.each do |tool| puts tool end # while count = 0 while count < 5 puts count count += 1 end

5. الدوال

def greet(name) "أهلاً #{name}" end def add(a, b) a + b end puts greet("Ahmed") puts add(5, 3)

6. الكلاسات (OOP)

class User def initialize(name, age) @name = name @age = age end def greet "أهلاً #{@name}" end end user = User.new("Ahmed", 25) puts user.greet

7. المصفوفات والهاش

tools = ["nmap", "hydra", "sqlmap"] user = { "name" => "Ahmed", "age" => 25 } puts tools[0] puts user["name"] # Symbol keys user = { name: "Ahmed", age: 25 } puts user[:name]
