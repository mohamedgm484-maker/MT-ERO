Kotlin

لغة Android الرسمية

يعني إيه Kotlin؟

Kotlin هي لغة برمجة من JetBrains، بتستخدم في تطوير تطبيقات الأندرويد. بتعتبر اللغة الرسمية للأندرويد من Google.

بتتميز بالبساطة والأمان — وبتشتغل على JVM و Android و JavaScript.

الأساسيات

1. البرنامج الأول

fun main() { println("Hello World") }

2. المتغيرات

// Mutable var name = "Ahmed" name = "Mohamed" // Immutable val pi = 3.14 // Types val age: Int = 25 val salary: Double = 5000.50 val isHacker: Boolean = true println(name) println(age)

3. الشروط

val age = 20 if (age >= 18) { println("بالغ") } else if (age >= 13) { println("مراهق") } else { println("طفل") } // When (Switch) when (age) { 18 -> println("18 سنة") in 19..30 -> println("شاب") else -> println("تاني") }

4. الحلقات

for (i in 0..4) { println(i) } var count = 0 while (count < 5) { println(count) count++ } val tools = listOf("nmap", "hydra") tools.forEach { println(it) }

5. الدوال

fun greet(name: String): String { return "أهلاً $name" } fun add(a: Int, b: Int) = a + b println(greet("Ahmed")) println(add(5, 3))

6. Classes

class User(val name: String, val age: Int) { fun greet() = "أهلاً $name" } fun main() { val user = User("Ahmed", 25) println(user.greet()) } // Data Class data class Product(val name: String, val price: Double) val p = Product("Laptop", 5000.0) println(p)
