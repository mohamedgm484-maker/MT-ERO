Swift

لغة Apple لتطوير iOS و macOS

يعني إيه Swift؟

Swift هي لغة برمجة من Apple، بتستخدم في تطوير تطبيقات iOS و macOS و watchOS و tvOS.

بتعتبر اللغة الأساسية لتطوير iPhone — وبتتميز بالسرعة والأمان.

الأساسيات

1. البرنامج الأول

print("Hello World")

2. المتغيرات

// Variable var name = "Ahmed" name = "Mohamed" // Constant let pi = 3.14 // Types let age: Int = 25 let salary: Double = 5000.50 let isHacker: Bool = true print(name) print(age)

3. الشروط

let age = 20 if age >= 18 { print("بالغ") } else if age >= 13 { print("مراهق") } else { print("طفل") }

4. الحلقات

for i in 0..<5 { print(i) } var count = 0 while count < 5 { print(count) count += 1 } let tools = ["nmap", "hydra"] for tool in tools { print(tool) }

5. الدوال

func greet(name: String) -> String { return "أهلاً \(name)" } func add(_ a: Int, _ b: Int) -> Int { return a + b } print(greet(name: "Ahmed")) print(add(5, 3))

6. Classes و Structs

struct User { var name: String var age: Int func greet() -> String { return "أهلاً \(name)" } } let user = User(name: "Ahmed", age: 25) print(user.greet())
