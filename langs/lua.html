Lua

لغة خفيفة لـ Scripting

يعني إيه Lua؟

Lua هي لغة برمجة نصية خفيفة وسريعة. بتستخدم في الألعاب (Roblox, WoW)، الأنظمة المدمجة، وتطبيقات الأدوات.

بتعتبر الأشهر في مجال Scripting الألعاب — وبتحتل مكانة كبيرة في Scripting في الألعاب.

الأساسيات

1. البرنامج الأول

print("Hello World")

2. المتغيرات

name = "Ahmed" age = 25 salary = 5000.50 is_hacker = true print("أهلاً " .. name) print("عمرك " .. age)

3. الشروط

age = 20 if age >= 18 then print("بالغ") elseif age >= 13 then print("مراهق") else print("طفل") end

4. الحلقات

-- For for i = 0, 4 do print(i) end -- While count = 0 while count < 5 do print(count) count = count + 1 end -- For in tools = {"nmap", "hydra", "sqlmap"} for i, tool in ipairs(tools) do print(tool) end

5. الدوال

function greet(name) return "أهلاً " .. name end function add(a, b) return a + b end print(greet("Ahmed")) print(add(5, 3))

6. الجداول (Tables)

tools = {"nmap", "hydra", "sqlmap"} print(tools[1]) user = { name = "Ahmed", age = 25 } print(user.name)
