PHP

لغة تطوير الويب من جهة السيرفر

يعني إيه PHP؟

PHP (Hypertext Preprocessor) هي لغة برمجة نصية بتشتغل على السيرفر. بتستخدمها لتطوير مواقع ويب ديناميكية وتطبيقات ويب كاملة.

بتعتبر من أشهر لغات تطوير الويب — ومواقع كتير زي Facebook و WordPress بتستخدمها. وفي الأمن السيبراني، PHP مهمة لفهم ثغرات الويب.

استخدامات PHP

  • تطوير المواقع الديناميكية
  • أنظمة إدارة المحتوى (WordPress)
  • الـ APIs
  • المتاجر الإلكترونية
  • أنظمة تسجيل الدخول

التثبيت

pkg install php -y php --version

الأساسيات

1. البرنامج الأول

<?php echo "Hello World"; ?>

2. المتغيرات

<?php $name = "Ahmed"; $age = 25; $salary = 5000.50; $is_hacker = true; echo "أهلاً $name"; echo "عمرك $age"; ?>

3. الشروط

<?php $age = 20; if ($age >= 18) { echo "بالغ"; } elseif ($age >= 13) { echo "مراهق"; } else { echo "طفل"; } ?>

4. الحلقات

<?php for ($i = 0; $i < 5; $i++) { echo $i; } $count = 0; while ($count < 5) { echo $count; $count++; } $tools = ["nmap", "hydra"]; foreach ($tools as $tool) { echo $tool; } ?>

5. الدوال

<?php function greet($name) { return "أهلاً $name"; } function add($a, $b) { return $a + $b; } echo greet("Ahmed"); echo add(5, 3); ?>

6. المصفوفات

<?php $tools = ["nmap", "hydra", "sqlmap"]; $user = [ "name" => "Ahmed", "age" => 25 ]; echo $tools[0]; echo $user["name"]; ?>

7. النماذج (Forms)

<?php if ($_SERVER["REQUEST_METHOD"] == "POST") { $name = $_POST["name"]; $email = $_POST["email"]; echo "أهلاً $name"; } ?> <form method="POST"> <input type="text" name="name"> <input type="email" name="email"> <input type="submit"> </form>

8. التعامل مع قواعد البيانات

<?php $conn = new mysqli("localhost", "user", "pass", "mydb"); if ($conn->connect_error) { die("Connection failed"); } $sql = "SELECT * FROM users"; $result = $conn->query($sql); while ($row = $result->fetch_assoc()) { echo $row["name"]; } $conn->close(); ?>
