Dart

لغة Flutter لتطوير الموبايل

يعني إيه Dart؟

Dart هي لغة برمجة من Google، بتستخدم في تطوير التطبيقات (موبايل، ويب، ديسكتوب) باستخدام Flutter.

بتعتبر بديل ممتاز لتطوير تطبيقات تعمل على Android و iOS بكود واحد.

الأساسيات

1. البرنامج الأول

void main() { print("Hello World"); }

2. المتغيرات

String name = "Ahmed"; int age = 25; double salary = 5000.50; bool isHacker = true; // Dynamic var city = "Cairo"; print(name); print(age);

3. الشروط

int age = 20; if (age >= 18) { print("بالغ"); } else if (age >= 13) { print("مراهق"); } else { print("طفل"); }

4. الحلقات

for (int i = 0; i < 5; i++) { print(i); } int count = 0; while (count < 5) { print(count); count++; } var tools = ["nmap", "hydra"]; tools.forEach((tool) => print(tool));

5. الدوال

String greet(String name) { return "أهلاً $name"; } int add(int a, int b) => a + b; void main() { print(greet("Ahmed")); print(add(5, 3)); }

6. Classes

class User { String name; int age; User(this.name, this.age); String greet() { return "أهلاً $name"; } } void main() { var user = User("Ahmed", 25); print(user.greet()); }
