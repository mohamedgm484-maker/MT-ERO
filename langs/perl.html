Perl

لغة معالجة النصوص والأتمتة

يعني إيه Perl؟

Perl هي لغة برمجة نصية قوية، بتستخدم في معالجة النصوص، الأتمتة، وإدارة الأنظمة. بتعتبر "سكين الجيش السويسري" في اللغات.

بتستخدمها شركات كتير في الـ Web والأنظمة — وفي الأمن السيبراني بتستخدم في كتابة الـ Exploits.

الأساسيات

1. البرنامج الأول

#!/usr/bin/perl use strict; use warnings; print "Hello World\n";

2. المتغيرات

my $name = "Ahmed"; my $age = 25; my $salary = 5000.50; print "أهلاً $name\n"; print "عمرك $age\n";

3. الشروط

my $age = 20; if ($age >= 18) { print "بالغ\n"; } elsif ($age >= 13) { print "مراهق\n"; } else { print "طفل\n"; }

4. الحلقات

# For for (my $i = 0; $i < 5; $i++) { print "$i\n"; } # Foreach my @tools = ("nmap", "hydra", "sqlmap"); foreach my $tool (@tools) { print "$tool\n"; } # While my $count = 0; while ($count < 5) { print "$count\n"; $count++; }

5. الدوال

sub greet { my ($name) = @_; return "أهلاً $name"; } sub add { my ($a, $b) = @_; return $a + $b; } print greet("Ahmed") . "\n"; print add(5, 3) . "\n";

6. معالجة النصوص

my $text = "Hello World"; # بحث واستبدال $text =~ s/World/Perl/; print "$text\n"; # بحث if ($text =~ /Perl/) { print "لقيت Perl\n"; } # فصل my @words = split(/ /, $text); print join(" | ", @words) . "\n";

7. الملفات

# قراءة open(my $fh, "<", "file.txt") or die "مش قادر أفتح"; while (my $line = <$fh>) { print $line; } close($fh); # كتابة open(my $out, ">", "output.txt") or die "مش قادر أكتب"; print $out "Hello World\n"; close($out);
