Java

لغة الأنظمة الكبيرة والأندرويد

يعني إيه Java؟

Java هي لغة برمجة كائنية التوجه (OOP)، بتستخدم في الأنظمة الكبيرة، تطبيقات الأندرويد، وتطبيقات الويب.

بتعتبر من أشهر اللغات في العالم — وبتستخدمها شركات كتير زي Netflix و Amazon و Twitter. وكمان هي اللغة الأساسية لتطوير الأندرويد.

استخدامات Java

  • تطبيقات الأندرويد
  • تطبيقات الويب (Spring)
  • الأنظمة الكبيرة (Enterprise)
  • تطبيقات الديسكتوب
  • الألعاب (Minecraft)

الأساسيات

1. البرنامج الأول

public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }

2. المتغيرات

int age = 25; double salary = 5000.50; String name = "Ahmed"; boolean isHacker = true; char letter = 'A'; System.out.println(name); System.out.println(age);

3. الشروط

int age = 20; if (age >= 18) { System.out.println("بالغ"); } else if (age >= 13) { System.out.println("مراهق"); } else { System.out.println("طفل"); }

4. الحلقات

for (int i = 0; i < 5; i++) { System.out.println(i); } int count = 0; while (count < 5) { System.out.println(count); count++; }

5. الدوال

public static int add(int a, int b) { return a + b; } public static void greet(String name) { System.out.println("أهلاً " + name); } public static void main(String[] args) { System.out.println(add(5, 3)); greet("Ahmed"); }

6. الكلاسات (OOP)

public class User { private String name; private int age; public User(String name, int age) { this.name = name; this.age = age; } public String getName() { return name; } public int getAge() { return age; } } public class Main { public static void main(String[] args) { User user = new User("Ahmed", 25); System.out.println(user.getName()); } }
